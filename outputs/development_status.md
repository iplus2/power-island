# 工程状态与验证

更新：2026-10-03。规则以 core_game_spec.md v0.6 为准。

## 当前实现

- 1v1/2v2、房间码、匿名重连、选队与经同意交换、随机房主继任、重赛。
- 200 ms 权威 tick；整数 Power、储备、生产、转移、战斗、重生与团队结算。
- 个人分区的部署信息、Core 两步确认、团队当前视野、服务端隐藏数据过滤。
- 地图点按直线目标移动与 WASDEQ；拖动、多指和取消不触发点按，保留网页滚动/缩放。
- 海岸适配地图框以减少水域留白；Canvas 跟随像素密度与网页缩放；仅 playing 禁止文字选择。
- 地图按版本初始化、变化元数据同步、完整 5 Hz 动态集合；Leave 和断线超时清理席位/session。

本轮前后端已配套发布，旧版本保留用于回退。公开仓库不保存实际部署身份或连接信息。

## 验证证据

- 类型检查、生产构建及 38 项规则/输入/Socket.IO/React 测试通过。
- 3 项 Chromium 流程通过：桌面 1v1、四客户端含手机尺寸的 2v2、DPR3 触屏与原生页面缩放。包含两步部署、手势取消、目标更新、失焦停止和退出。
- 双人固定 seed 静止开局，state JSON 载荷从 465.416 降至 59.416 kb/s（约减少 87.23%）。每阶段预热 300 ms、采样 2 秒；仅计事件 JSON UTF-8 字节，不含初始化、输入、ACK、帧、TLS 或网卡开销，不能外推全场流量。原始记录在 verification/。
- 服务端四房间十二 WebSocket 客户端实际移动运行 60 秒通过；公网两个房间六客户端 1v1/2v2、部署隐私、移动、投降及退出通过。测试结束后房间归零。
- 用户在桌面浏览器确认地图显示有改善。
